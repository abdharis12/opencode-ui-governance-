# CREATIVE DIRECTION

The agent is encouraged to make bold, distinctive, and intentional visual decisions.

Do not produce safe, generic, repetitive, or template-like interfaces merely for the sake of consistency.

Consistency does NOT mean every page should look identical.

Consistency means every page should clearly belong to the same product.

---

# CREATIVE FREEDOM

The agent MAY make strong creative decisions regarding:

* layout
* composition
* asymmetry
* visual hierarchy
* typography scale
* spacing rhythm
* content emphasis
* visual storytelling
* product visualization
* illustration composition
* section transitions
* micro-interactions
* animation choreography
* signature visual elements
* information density

The agent SHOULD avoid generic layouts when a more appropriate composition can better express the purpose of the page.

---

# NON-NEGOTIABLE BOUNDARIES

Creative direction MUST remain within:

1. Driveku brand identity
2. Claymorphism visual language
3. Approved Design Tokens
4. shadcn/ui component foundation
5. Radix UI interaction/accessibility foundation
6. Existing product vocabulary
7. Existing usability conventions

Creative freedom does NOT permit replacing these foundations.

---

# DESIGN PHILOSOPHY

The objective is:

**Distinctive within the system.**

Not:

**Identical across every page.**

A Dashboard, File Manager, Document Preview, Settings page, and Landing Page may have different compositions.

However, users should immediately recognize them as belonging to Driveku.

---

# AVOID GENERIC AI DESIGN

Do not default to common AI-generated patterns simply because they are familiar.

Examples:

* generic centered hero
* predictable three-card feature grid
* excessive rounded cards
* meaningless gradient backgrounds
* random floating blobs
* oversized statistics
* decorative numbered sections
* generic SaaS layouts
* excessive glassmorphism
* arbitrary dark-mode aesthetics

Only use these patterns when they genuinely fit the content.

---

# TAKE A DESIGN RISK

For major pages, deliberately explore at least one distinctive visual idea.

The idea must be justified by the page's purpose.

Examples for Driveku:

* document-stack hero
* tactile folder navigation
* archive-inspired composition
* layered document preview
* spatial file hierarchy
* physical-desk-inspired document organization
* dimensional folder metaphor

The risk should make the page memorable without making it confusing.

---

# ONE SIGNATURE

Spend most of the creative boldness in one meaningful signature element.

Keep supporting elements disciplined.

Do not make every component visually loud.

The page should have:

**one memorable idea + strong execution + disciplined supporting UI.**

---

# SELF-CRITIQUE

Before finalizing, ask:

### Is it distinctive?

Would the layout be recognizable as intentionally designed rather than generated from a generic template?

### Is it Driveku?

Does the design draw visual meaning from documents, files, folders, digital archives, or government workflows?

### Is it Claymorphism?

Does the page use tactile surfaces, depth, elevation, soft highlights, and pressed states coherently?

### Is it coherent?

Does it still feel related to the rest of Driveku?

### Is it restrained?

Are there decorative elements that can be removed without harming the design?

If yes, remove them.

---

# FINAL PRINCIPLE

Do not optimize for:

"safe consistency."

Optimize for:

**"recognizable consistency with distinctive expression."**
